# Streaming

Being told, rather than asking.

## Overview

``Server/connected(attachingTo:_:)`` hands back the connection alongside the
server, because reporting what changed without being asked is the one thing a
connection can do and a process cannot:

```swift
let firstLine: String? = try await server.connected(attachingTo: "work") { server, events in
    for await notification in events.notifications
    where notification.name == "output" {
        return notification.arguments
    }
    return nil
}
```

There is no way to write this against a server that has no connection — the
value carrying the stream exists only inside the scope that opened one.

The loop leaves on the notification it was waiting for, and the stream ends by
itself when the connection closes, which is what the `nil` answers. A loop with
no way out is the easy thing to write here and the hard thing to stop: it holds
the connection open for as long as the server lives.

## What it saves

Polling ``Server/capture(_:includingHistory:)`` cannot answer sooner than its
interval, and each tick it takes costs a tmux process and a round trip.
Streaming has neither floor nor tick: the connection is paid for once and the
waiting itself is free, however long it lasts.

Those are polling's best case — the line was already on screen when the first
capture ran, so it spent one process on the command and one on the capture that
found it. A line that takes longer to appear costs polling another of each per
tick and streaming nothing at all. The benchmark prints latencies too, which are
medians that move with the machine; run it for those.

## Lifetime

The connection is scoped to the closure: a live process handed out as a value
would be a value that lies. When the closure returns, the connection closes and
the child is reaped before the call does. A command still waiting at that point
fails with ``TmuxError/connectionClosed`` rather than hanging.

``Server/withControlMode(attachingTo:_:)`` is the layer beneath, for speaking
the control protocol directly.
